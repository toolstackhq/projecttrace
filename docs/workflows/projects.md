# Projects

Projects are the top-level container for all planning and testing work.

## What a project contains

- epics
- features
- requirements
- test cases
- test runs
- bugs
- activity logs

## Create a project

1. Open `Planning -> Projects`.
2. Click `Create project`.
3. Enter:
   - name
   - description
   - owner
4. Save the record.

## Ownership rule

A project must have an owner.

If no users exist yet, create a user first from `System -> Users` or from the login bootstrap flow.

## Working with projects

- Use search to find a project quickly.
- Open a project to view its epics, features, requirements, test cases, bugs, and activity.
- Keep owner assignments current so the workspace stays accountable.
